## Overview
The Quiz App (Arabic Edition) is a lightweight, high-performance web application designed to provide an engaging trivia experience. Built specifically for users in the GCC region, this app features full Right-to-Left (RTL) support and cultural considerations, making it perfect for educational purposes, corporate training, or casual entertainment.

## Features
*   **Dynamic Progress Tracking:** Visual progress bar to keep users informed.
*   **Timed Challenges:** Built-in timer to increase engagement and difficulty.
*   **RTL Optimization:** Fully localized layout using CSS Flexbox/Grid for a seamless Arabic user experience.
*   **Instant Feedback:** Immediate score calculation upon completion.
*   **Restart Option:** Easily reset the quiz to try again.
*   **Zero Dependencies:** Pure Vanilla JavaScript for lightning-fast load times.
